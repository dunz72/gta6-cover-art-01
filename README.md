Neon Vice — turn a photo and a caption into GTA 6-style cover art, offline in your desktop browser. Multi-panel layouts (Hero + 2, Triptych, Quad, Solo), sunset/neon/noir/vice colour grades, drag-to-pan and scroll-to-zoom crops, and one-click PNG export in 1080×1080, 1080×1350, 1920×1080 and 1080×1920. All original art — no Rockstar logo, artwork or fonts — and photos never leave the machine.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```

Build the hand-in (copies app/ + screenshots/ and writes dossier.json):

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
